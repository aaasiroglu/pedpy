# 06: Açık Sorular

Yanıtlandıkça buraya not düşülecek ve ilgili karar [05_karar_gunlugu.md](05_karar_gunlugu.md) dosyasına işlenecek.

## Size (öğrenciye)

1. **Tez teslim ve savunma tarihi** nedir? Yol haritası göreli aylarla yazıldı (A1–A12).
2. **Danışman:** Hande Demirel mi (İTÜ Geomatik Mühendisliği)? README'deki atıf bloğu bunu ima ediyor. Danışmanın Alpagut ve Koçyiğit ile ortak çalışmaları tezin doğal öncülü.
3. **İBB verisine erişiminiz var mı, yoksa talep mi edilecek?** Hangi katmanlar mevcut: LiDAR/DSM, bina envanteri, yapı adası sınırları?
4. **Gerçek tüketim verisi** (sayaç veya fatura, toplulaştırılmış hâliyle) temin edilebilir mi? Bu, R5 riskini büyük ölçüde azaltır.
5. **Bonus katmanlar** (NLP-1, NLP-2, Graf-2) içinden hangileri sizin için öncelikli? "Etkileyici" hedefini en iyi hangisi karşılar: XAI + Graf mi, yoksa XAI + NLP mi? Benim önerim: **XAI + Graf çekirdekte, NLP-2 (sadık Türkçe açıklamalar) bonus olarak.** Kullanıcı çalışması etik kurul gerektirdiği için NLP-1'i makale aşamasına bırakmak daha güvenli.
6. Tez **Türkçe mi İngilizce mi** yazılacak? Kod ve API İngilizce, belgeler Türkçe olarak önerildi.
7. GitHub kullanıcı adı ve lisans tercihi: **MIT mi, Apache-2.0 mı?** README'de ikisi birden geçiyor.

## Danışmana

1. AS1–AS7 içinden tezin kapsamı. Zorunlu katmanın onayı.
2. ρ* eşiği (öneri: 0,80, bootstrap güven aralığıyla). Önceden kayda geçirmenin biçimi.
3. PAR tanımı: tepe/ortalama mı, tepe/tepe talep mi? (K-003)
4. PEB kapsamı: "elektrik odaklı PEB potansiyeli" sınırlaması kabul edilebilir mi? (R6)
5. Müdahale birim maliyetleri için Türkiye'de kabul gören kaynak hangisi? (Bakanlık birim fiyatları, piyasa teklifleri vb.)
6. Hedef dergi ve konferans (ör. ISPRS, Applied Energy, SCS).
